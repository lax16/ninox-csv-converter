Ninox CSV Converter

Converts a Ninox backup (.ninox) into one CSV file per table. Everything happens in this browser tab — the backup is never uploaded.

Drop a .ninox backup here or click to choose Backups of several gigabytes are fine.
Output
Options
Converting…
TableFileRows

Columns: record ID, creation and modification date (Unix ms), then all fields. Reference fields are suffixed with -ref and contain the referenced record's ID. File fields contain the attachment's path relative to the CSV, e.g. files/Fahrzeuge/11/vorne.jpg. Separator is ;, values are quoted per RFC 4180.
